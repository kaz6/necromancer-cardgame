# CURRENT_SPEC（実装済みルール・v0.2-final）

# 対戦形式
- 2人対戦、ターン制。先攻は `createInitialState` の `options.first`（既定 p1）。
- 盤面は 3列 × 2段の6枠（前列＝row 0、後列＝row 1。`slot = row * 3 + col`）。
- 各プレイヤーに、盤面とは別にネクロマンサー1枚。
- 勝利条件は**相手のネクロマンサーの体力を0以下にすること、これだけ**。デッキ切れで負けない（下の「実装にないもの」）。

# ネクロマンサー
- 体力 **12**、攻撃力0、コスト0、能力なし。`data/cards.js` の `necromancer`。
- 自分では攻撃しない（攻撃の主体は盤面の駒だけ）。
- **相手の盤面が6枠すべて空のときだけ**攻撃できる（`rules.necromancerProtectedWhileBoardOccupied = true`）。ダメージは戦闘と違って反撃を受けない。
- 受けたダメージは回復しない。体力が0以下になった瞬間に決着。撃破時に発動する効果（c07）はその場で解決しない。

# 初手とドロー
- 初手は先攻6枚・後攻7枚。デッキは両者30枚（下の構成）。
- **ドローは自動ではなく `draw` という行動**。1ターンに1回、1回で3枚（`rules.drawPerTurn = 3`）。先攻の1ターン目もドローできる（`firstPlayerDrawsOnTurn1 = true`）。
- 手札の上限はない（コード上に上限の判定がない）。

# 手番の流れ
- 1ターンの中で、次の行動を好きな順で、制限の範囲で行える: `draw`（1回）／`summon`／`attack`／`reposition`／`endTurn`。
- `endTurn` で相手の手番へ。相手側の各駒の攻撃済みフラグが戻り、相手のドロー済みフラグが戻る。持ち越した pt はここで消える。

# 召喚（ピッチコスト制）
- マナはない。手札からカードを**捨てる（ピッチ）**ことで支払いポイントを作る。ピッチは**手札からのみ**。
- 支払いポイント＝捨てたカードのコスト合計。出すカードのコスト合計（必要量）が、これ以下なら出せる。1回の召喚で何枚でも出せる（枠の数まで）。
- 出せるのは**空き枠のみ**。召喚元は**手札**または**自分の墓地**。
- **捨てたカードは相手の墓地へ行く。** 捨てたカード自身をその召喚で出すことはできない。
- 墓地から出す場合、判定は「ピッチで捨てる前」の墓地に対して行う（`summonSourcesSnapshotBeforePitch = true`）。
- 墓地から出したカードは、受けたダメージが消え、刷られた数値に戻り、c05 の退避権も戻る。
- 墓地に入ったカードは**入った直後から召喚できる**（`graveyardSummonBuffer = 0`）。1／2 にすると同手番／1手番またぎ。
- 召喚酔いはない（`summoningSickness = false`）。
- **余ったポイントは消える**（`pitchCarryover = false`）。true にすると同じ手番内の次の召喚に持ち越せ、ターン終了で消える。
- 召喚元の墓地は**自分の墓地**（`summonSource = ownGraveyard`）。

# 墓地
- 墓地は「そのプレイヤーが召喚に使える資源置き場」。**カードは置かれた墓地の持ち主が使える。**
- 自分の駒が死ぬ／自分が捨てる → **相手の墓地へ**。倒した駒・相手が捨てたカード → 自分の墓地へ。
- カードは「元の持ち主（owner・生涯変わらない）」と「いま使えるプレイヤー（controller）」を持つ。墓地へ入る・召喚するたびに controller が付け替わる。
- ★ **自分の墓地に、自分が元の持ち主のカードが入ることがある（里帰り）。** 相手の場に出た自分のカードが死ぬと、倒した側＝元の持ち主の墓地へ帰る。この企画ではこれを**仕掛けとして認める**（DECISION_LOG 2026-10-14「自分の場に出た駒は、死亡時、基本的に相手の墓地へ行く」）。v0.2-final のセルフテスト「自分の墓地に自分のカードが存在しない（一貫法則）」はこの裁定と矛盾する（SESSION_STATE の未確定項目 U2。NC-003 で直す）。
- 墓地のコスト合計を常時表示する。表示のみで、ゲーム効果はない。
- トークンは死んでも墓地へ行かず消滅する（下の「カード」）。

# 前列・後列
- 後列の駒は、**同じ列の前列に駒がいる間は攻撃対象にならない**（`backRowProtectedByFront = true`）。
- 攻撃する側は前列・後列どちらの駒でもよい。
- 配置換え（`reposition`）: 自分の駒を別の枠へ動かす。移動先が空なら移動、駒がいれば入れ替え。**コスト0・回数無制限**（`repositionCost = 0`、`repositionPerTurn = null`）。

# 戦闘
- 各駒は1ターンに1回攻撃できる（`attacksPerUnitPerTurn = 1`）。攻撃力0の駒は攻撃できない。
- **先攻の1ターン目も攻撃できる**（`firstPlayerAttacksOnTurn1 = true`）。false にすると、先攻の最初の手番はユニットにもネクロマンサーにも攻撃できない（召喚・配置換えは制限しない）。
- 駒同士の戦闘は**同時にダメージを与え合う**（反撃あり・相打ちあり）。受けたダメージは、その駒が場にいる間は残り続け、回復しない。
- 死亡の処理順は「守り手 → 攻め手」で固定。倒れた駒は、c05 の退避に成功しない限り**倒した側の墓地**へ行く（トークンは消滅）。

# カード（8種＋トークン）
- カード名は「モンスターA〜H」で固定（プロト段階では固有名を付けない）。
- c01 モンスターA: コスト1・1/1・能力なし
- c02 モンスターB: コスト2・1/3・能力なし
- c03 モンスターC: コスト3・3/2・能力なし
- c04 モンスターD: コスト5・5/4・能力なし
- c05 モンスターE: コスト2・1/2。倒されたとき、1/1 になって後列へ移動する（1回きり）。
- c06 モンスターF: コスト3・2/3。場に出たとき、右の空き枠に 1/1 のトークンを出す。
- c07 モンスターG: コスト4・4/2。相手のカードを倒したとき、相手のデッキの一番上1枚を自分の墓地へ送る。
- c08 モンスターH: コスト4・2/5。呪い。相手の墓地にある間、相手が墓地から召喚する最初の1回に、支払いポイントを1多く必要とする。
- t01 トークン: コスト0・1/1。デッキには入らない。倒されると墓地へ行かず消滅する（`tokens.list[].onDeath = vanish`）。
- 数値が「コスト・攻撃/体力」。デッキ（30枚）: c01×5・c02×5・c03×4・c04×2・c05×4・c06×4・c07×4・c08×2。両者とも同じ。

## 能力の細部（コードで確認済み。`rules.abilities` でフラグ化）
- c05: 後列に空きがなければ不発で、通常どおり倒した側の墓地へ（`deathRetreatNoRoom = toGraveyard`）。退避先は同じ列の後列を優先、埋まっていれば後列を左から（`deathRetreatSlotOrder = sameColumnFirst`）。後列で倒れたときはその枠に留まる。退避しても「倒された」事実は残り、c07 の効果は乗る。退避後に再度倒されたら通常どおり墓地へ。
- c06: 右が埋まっている・右端に出たときは何も起きない。トークンの持ち主は出した側。複数体を同時に出したときは枠の昇順で解決。
- c07: 反撃で倒したときも発動する（`killTriggerOnCounterattack = true`）。相手のデッキが空なら何も起きない。送られたカードは自分の墓地に入り、controller は自分になる（元の持ち主は相手のまま）。
- c08: 墓地から出す召喚に乗る追加支払い。何体まとめて出しても1回の召喚につき1回。複数あれば加算してまとめて全部発動（`curseStacking = add`）。一度発動したら、墓地に留まっていても再発動しない。墓地へ入り直せば数え直す。持ち越し pt でも支払える。

# 視点フィルタ（filterStateFor）
- `filterStateFor(state, playerId)` がそのプレイヤーに見せてよい情報だけを残す。**相手の手札の中身と、両者のデッキの中身は落とす（枚数だけ残す）。乱数の状態（rng）も落とす。**
- 盤面・墓地・ネクロマンサー・自分の手札・ログは見える。
- LAN 対戦のサーバ（`server.js`）は各クライアントにこれを通した state だけを返す。ただし**シード値そのものは通信に載っている**（SESSION_STATE の未確定項目 U1。NC-003 で直す）。

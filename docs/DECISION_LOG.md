# 2026-10-14　奪う対象と手段：目の前のアイツを殺して、蘇らせて配下にする
- 決めたこと：奪う対象は相手の場で生きているカード。手段は「リソースを割いて殺し、蘇らせて配下にする」。体験させたいシチュは「いま眼の前にいるアイツが欲しい。殺して奪う」（作者）
- 理由：作りたい体験「敵のあいつがいれば面白いコンボができる」の「あいつ」は、場にいる特定の1体を指す
- 却下した案：
	- 生きたまま相手の場からもぎ取る（サクリファイス型）。チャット側の読みとして一度記録したが、作者が訂正
	- 相手が落としたもの（倒された・払われたカード）を墓地から拾うのを主役にする形（v0.2 の形）。狙いの1体を特別扱いできない
- 根拠：作者の発言（チャット 2026-10-14）

# 2026-10-14　駒は時限で朽ちる。崩れたら死亡扱い
- 決めたこと：駒は「朽ちゆく体を無理やり動かされている」もの。場に出たら時限式で暴れる。時限で朽ちて崩れた場合も死亡に含む（作者）。寿命の数え方は未決。最初のモックは「残り○ターン」で作る
- 理由：多くのカードゲームのように、出たら猛威を振るい続けるのではないものにしたい（作者）。チャット側の整理（推測）：奪った敵もいずれ朽ちるので、却下済みの「倒したカードを即座に自分の場へ置き直す」の却下理由（snowball）への答えになりうる
- 却下した案：なし（「灰」を新しい資源にする形は 2026-08-14 に却下済み。イメージとしてだけ使う）
- 根拠：作者の発言（チャット 2026-10-14）

# 2026-10-14　自分の場に出た駒は、死亡時、基本的に相手の墓地へ行く
- 決めたこと：自分の場に出た駒は、死亡時（朽ちて崩れた場合を含む）、基本的に相手の墓地へ行く。固有効果による例外はありうる（作者）
- 帰結：相手の駒を殺す → 自分の墓地 → 呼べる。奪った駒が自分の場で死ぬ → 元の持ち主の墓地へ帰る → 取り返せる。奪い合いの往復が起きる
- 帰結：v0.2 の未裁定「里帰りの表現」（元の企画の SESSION_STATE の要裁定3）は、この企画では**里帰りを仕掛けとして認める**形で決着。v0.2-final のセルフテストにある「自分の墓地に自分のカードが存在しない」は、この企画のルールでは誤り（NC-001 で、CPU 同士 500 戦で里帰り 4,681 回を確認）
- 理由：作者は「奪ったカードがずっと自分のものか、相手へ帰るか」について「どちらとも言えない。奪い合いも発生してほしい」と答えていた。この法則でそれが往復として実現する
- 却下した案：奪った駒は死んでもずっと自分のもの（往復が起きない）
- 根拠：作者の発言（チャット 2026-10-14）、NC-001 の報告
